Reichweitenmessung: Seitenaufrufe und Klicks auf externe Links

Wenn du eine Seite dieser Website öffnest, sendet dein Browser eine kurze Meldung an unseren Zähler. Übertragen werden nur die aufgerufene Unterseite und der Name der Website, von der du gekommen bist (zum Beispiel pinterest.de, ohne genaue Adresse). Gespeichert wird daraus nur eine Tagessumme: wie oft eine Unterseite an einem Tag aufgerufen wurde, grob eingeteilt nach Herkunft (zum Beispiel Pinterest, Instagram, Suchmaschine oder direkt). Einzelne Aufrufe, Uhrzeiten oder Geräteangaben werden nicht gespeichert.

Wenn du auf dieser Website einen Link zu einer anderen Seite anklickst, zum Beispiel zu Instagram, TikTok oder einem Partnerangebot, sendet dein Browser eine kurze Meldung an unseren Klickzähler. Gespeichert werden nur der Zeitpunkt, das Link-Ziel und die Unterseite, auf der du geklickt hast. Wir speichern keine IP-Adresse, setzen keine Cookies, vergeben keine Kennung und können Aufrufe und Klicks keiner Person zuordnen. So sehen wir, welche Inhalte und Empfehlungen gefragt sind.
